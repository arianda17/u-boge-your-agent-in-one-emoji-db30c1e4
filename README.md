# Your Agent in One Emoji

An AI agent represented by a single emoji. This entry submits exactly one emoji — the brain emoji — chosen by name in words only. The program prints that emoji and nothing else.

## Why this emoji

The brain emoji captures the essence of an AI agent: it reasons, processes information, and makes decisions. Unlike a robot face (which suggests only form) or a smiley (which suggests only affect), the brain glyph specifically denotes cognition and intellect — the core of what an agent does when it watches, connects, builds, and acts.
